# 介護福祉士 パート合格 | Kaigo Part (PWA)

日本の介護福祉士国家試験における「パート合格制度」および特定技能1号の滞在延長特例に対応した、フィリピン人介護人材向けの超軽量学習PWA（Progressive Web App）です。

低帯域・オフライン環境を前提とし、ビルドステップ完全ゼロの単一HTML構成で設計されています。

---

## 🌟 主な特徴

* **新制度「パート合格」特化型アーキテクチャ**
* 厚生労働省の新試験基準に準拠し、全389問の過去問データを A（現場実務・生活支援） / B（医療・身体理解） / C（総合事例） の3パートに分類。
* すでに合格（免除）したパートを LocalStorage に保存し、未合格の弱点パートだけに絞って効率的に反復学習が可能。


* **1セッション10問のサンプリング出題**
* 巨大な問題プール（A: 218問 / B: 140問 / C: 31問）から毎回ランダムに10問を抽出。日々の短いスキマ時間で飽きずに周回可能。


* **フィリピン人学習者に寄り添うローカライズ**
* **2,958箇所のふりがな（ルビ）自動展開**: 漢字に苦手意識のある学習者のため、ワンタップでルビの表示/非表示（`<ruby>`）を切り替え可能。
* **現場目線のタガログ語ワンポイント解説 (`tip_tl`)**: 単なる直訳ではなく、日本の介護現場の知恵やニュアンスを伝える実践的な解説を全問に収録。
* **Web Speech API による音声読み上げ**: 日本語の正しい発音とイントネーションをワンタップで確認。


* **ブランド音響アイデンティティ（437Hz）**
* Web Audio API を活用し、正解・不正解の判定時に 437Hz のサイン波トーンを動的生成。外部音声ファイルの読み込みオーバーヘッドをゼロに抑制。

## 🚀 デプロイ・実行方法

### ローカルでの動作確認

`index.html` を任意のWebブラウザで直接開くだけで即座に動作します（サーバー環境やNode.js等は不要です）。

### 本番公開（Vercel）

1. 本リポジトリを GitHub に push します。
2. Vercel にリポジトリをインポートします（Framework Preset は `Other`、Root Directory は `./` のままで設定不要）。
3. デプロイ完了後、発行されたURLにスマートフォン等のブラウザからアクセスし、「ホーム画面に追加」を実行することで、完全オフライン対応のスタンドアロンアプリとしてインストールされます。
